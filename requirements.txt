# 1. The reproduction notebook, which needs no account, no credentials and no
#    payment. Open it locally or upload the single file to Google Colab and run all
#    cells. It downloads about 190 MB from the public dataset named in README.md,
#    recomputes the reported numbers from the per-fill data, and asserts each one
#    against the committed expectations, failing the run if any check does not pass.
#
#      notebooks/counterparty_adverse_selection.ipynb

#      python3 checks/run_all_checks.py

# 3. The pipeline itself. It has nine groups and one entry point each. An entry
#    point with no flags prints what it would recompute and what that would cost and
#    computes nothing; --run recomputes the group, and --only brings one node or one
#    named quantity up to date together with everything upstream of it.
#
#      python3 run/data.py            python3 run/money.py
#      python3 run/markout.py         python3 run/controls.py
#      python3 run/persistence.py     python3 run/gates.py
#      python3 run/identity.py        python3 run/notebook.py
#      python3 run/quoters.py
